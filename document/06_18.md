# 2026-06-18 작업 내역

## 1. 프롬프트 개선 (`llm_analyzer.py`)

- 점수 기준 구간별 앵커 추가 (0~2 / 3~5 / 6~8 / 9~10 예시)
- 점수 방향 명시 — `(높을수록 위험)` / `(높을수록 좋음)` 표기
- `overallRisk` 계산 규칙 추가 — emotionalStability·cognitiveScore 낮으면 가중
- `summary` — 수치가 아닌 실제 발화 기반 2~3문장 + 예시 제공
- `recommendation` — riskLevel별 구체적 행동 가이드 명시
- `adherenceRecords` — 통화에서 언급된 슬롯만 생성, `isNeeded`·`isDone` 판단 기준 명시
- `temperature=0` 추가 (동일 통화 반복 호출 시 결과 일관성 확보)

## 2. AI 서버 안정성 강화

### `schemas.py`
- `field_validator` 추가 — 모든 점수 필드(depressionScore 등) 0~10 범위 클리핑

### `main.py`
- `resolve_risk_level()` 추가 — overallRisk 기준으로 riskLevel 서버에서 재계산 (LLM 불일치 방지)
- `fix_adherence_records()` 수정 — 잘못된 slot을 BREAKFAST로 대체하던 로직을 skip으로 변경
- 빈 통화 조기 처리 — 모든 answer가 빈 문자열이면 LLM 호출 없이 400 반환
- 시작 시 환경변수 검증 — `OPENAI_API_KEY` 없으면 서버 시작 시점에 즉시 에러

### `llm_analyzer.py`
- OpenAI 클라이언트 lazy 초기화 — 모듈 로드 시점이 아닌 호출 시점에 초기화 (시작 검증 순서 보장)
- JSON 파싱 재시도 — 실패 시 최대 2회 재시도, 3회 모두 실패하면 원문 포함해서 에러
